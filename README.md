# Tupã Sports

E-commerce moderno construído com Next.js (App Router), Tailwind CSS e React.

## Funcionalidades

- Home com branding, promoções e produtos em destaque
- Catálogo com filtros por busca, tamanho, preço, marca e esporte
- Página de produto com avaliações, relacionados e CTA de compra
- Carrinho global com cupom
- Chat de atendimento simulado
- Fluxo opcional de login para finalização de compra

## Executar localmente

```bash
npm install
npm run dev
```
